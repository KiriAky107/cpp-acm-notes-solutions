按学习目标选择必读路线

第一遍学习不必把整本笔记从头读到尾。先选一条与自己当前目标相近的路线，完成其中的必读内容和练习，再根据做题时遇到的问题回查。下面的章号与目录一致；例如“五（十二）”表示“第五部分 → （十二）搜索”。

路线 适合的起点 第一轮的目标 阅读入口
零基础起步 还不能独立写出输入、判断和循环 把一段简单题意写成能运行的程序 先读语言主线，再接 ACM 入门主线
从 C 转到 C++ 已经会用 C 写数组、循环和函数 用引用、模板与 STL 简化实现 先补 C++ 的写法，再按题目学习算法
ACM 入门与比赛练习 能独立写基本程序，开始接触算法 完成常见入门题，并参加周赛 先学基础技巧，再学搜索、DP 与图论
C++ 系统学习 希望理解语言、标准库与对象设计 能解释类型、对象和资源的使用过程 顺序学习第一、第二部分，再用算法检验理解

必读是当前路线的学习主线；选读可以接在相关练习之后；回查是在题目用到某个接口或模板时打开。表中的阶段按从上到下的顺序推进，每个阶段先读讲解、手算例子，再独立完成对应练习。

从一个阶段进入下一个阶段

读完讲解后，合上答案，用小数据走一遍，再独立写出本阶段的一道题。能解释变量、判断、更新顺序和复杂度，就继续下一阶段；若卡在某一步，回到对应小节重做这个步骤。每阶段留下一道已经独立完成的题和一道需要复习的题，下一次学习从这两道题开始。

正文练习旁保留原题链接。后记后的附录给出 GitHub 题解仓库入口，按章节与题号查阅完整推导。先看题解中的“建模与推导”，自己接着实现；仍有困难时再看手算、图解与代码。复习时可以先关闭答案，只看原题重新完成。
