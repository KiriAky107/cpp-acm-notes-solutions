# P1075 质因数分解

[原题入口](https://www.luogu.com.cn/problem/P1075)

对应章节：五、数据结构与算法 → （五） 基础数论。

## （一） 任务与输出目标

一个数是两个不同质数的乘积，求较大的质因数。

## （二） 建模与推导

较小质因数不超过平方根。从 2 开始试除，第一次找到因子 d 时，它就是较小质数：合数因子的更小质因数早已被找到。较大质数为 n/d。

## （三） 手算与过程

n=21，首次找到 d=3，输出 7。

## （四） 带注释实现

[完整源文件](../../code/P1075.cpp)

```cpp
#include <bits/stdc++.h>
using namespace std;



int main() {
    long long n; cin >> n;
    for (long long d = 2; d * d <= n; ++d)
        if (n % d == 0) { cout << n / d << '\n'; break; } // 两因子中较大的是商。
}
```

头文件 `<bits/stdc++.h>` 汇总 GNU C++ 的常用标准库，包含本程序使用的流、容器与算法；这是序言竞赛模板中的包含方式。

## （五） 复杂度

时间 $O(\sqrt n)$，额外空间 $O(1)$。
