# CF742-A Arpa’s hard exam and Mehrdad’s naive cheat

[原题入口](https://codeforces.com/problemset/problem/742/A)

对应章节：五、数据结构与算法 → （六） 快速幂。

## （一） 任务与输出目标

输出 1378 的 n 次方的最后一位。

## （二） 建模与推导

只保留个位，相当于对 10 取模。8 的正整数幂个位依次为 8、4、2、6，下一次又回到 8，因此周期为 4。n=0 时幂等于 1；正指数按 n%4 查表。也可以用取模快速幂计算同一结果，周期表把重复计算进一步省掉。

## （三） 手算与过程

n=1,2,3,4 时分别为 8,4,2,6；n=5 返回 8。

## （四） 带注释实现

[完整源文件](../../code/CF742-A.cpp)

```cpp
#include <bits/stdc++.h>
#define int long long
#define endl '\n'
using namespace std;

void solve() {
    int n;
    cin >> n;
    int cycle[4] = {6, 8, 4, 2}; // 按正指数除以 4 的余数排列。
    cout << (n == 0 ? 1 : cycle[n % 4]) << '\n';
}

signed main() {
    ios::sync_with_stdio(false); // 关闭同步，使用 cin 与 cout 完成输入输出。
    cin.tie(0), cout.tie(0);

    int T = 1; // 本题读入一组数据。
    // cin >> T; // 题目给出测试组数时开启，并在 solve 中处理一组。
    while (T--)
        solve();
}
```

## （五） 复杂度

时间 $O(1)$，额外空间 $O(1)$。
