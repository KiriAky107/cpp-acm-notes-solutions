# CF996-A Hit the Lottery

[原题入口](https://codeforces.com/problemset/problem/996/A)

对应章节：三、解题方法论：从题意到代码 → （九） 建模与推导中的典型反例。

## （一） 任务与输出目标

用面额 100、20、10、5、1 凑金额，求最少张数。

## （二） 建模与推导

更小面额凑够一张较大面额的金额时，可以替换成更少的张数：5 张 1→1 张 5，2 张 5→1 张 10，2 张 10→1 张 20，5 张 20→1 张 100。因此最优方案中较小面额不会积累到可替换的数量，按大到小取商，再把余数交给下一面额即可。

## （三） 手算与过程

125=100+20+5，共 3 张；43=20+20+1+1+1，共 5 张。

## （四） 带注释实现

[完整源文件](../../code/CF996-A.cpp)

```cpp
#include <bits/stdc++.h>
#define int long long
#define endl '\n'
using namespace std;

void solve() {
    int n, answer = 0;
    cin >> n;
    for (int value : {100, 20, 10, 5, 1}) {
        answer += n / value; // 取走这一面额能覆盖的整份金额。
        n %= value;          // 剩余金额交给更小面额。
    }
    cout << answer << '\n';
}

signed main() {
    ios::sync_with_stdio(false); // 关闭同步，使用 cin 与 cout 完成输入输出。
    cin.tie(0), cout.tie(0);

    int T = 1; // 本题读入一组数据。
    // cin >> T; // 题目给出测试组数时开启，并在 solve 中处理一组。
    while (T--)
        solve();
}
```

## （五） 复杂度

五个面额，时间 $O(1)$，额外空间 $O(1)$。
