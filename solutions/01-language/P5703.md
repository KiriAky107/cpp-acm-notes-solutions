# P5703 苹果采购

[原题入口](https://www.luogu.com.cn/problem/P5703)

对应章节：一、C++ 语法基础 → （三） 常量、类型转换与整数溢出。

## （一） 任务与输出目标

每人分 a 个苹果，共 b 人，求采购数量。

## （二） 建模与推导

先手算三个人各分四个：4+4+4=12。每个人分到的数量相同，因此重复加法可以写成乘法，答案为 $ab$。让参与乘法的变量直接使用 long long，计算结果也使用这个类型。

## （三） 手算与过程

输入 `4 3`，把三份 4 合并成 12。

## （四） 带注释实现

[完整源文件](../../code/P5703.cpp)

```cpp
#include <iostream>
using namespace std;



int main() {
    long long a, b;
    cin >> a >> b;
    cout << a * b << '\n'; // 每人的数量乘人数，得到总数量。
}
```

## （五） 复杂度

时间 $O(1)$，额外空间 $O(1)$。
