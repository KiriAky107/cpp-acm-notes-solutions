# P1428 小鱼比可爱

[原题入口](https://www.luogu.com.cn/problem/P1428)

对应章节：一、C++ 语法基础 → （六） 原生数组与枚举；一、C++ 语法基础 → （十五） STL：容器、迭代器与算法。

## （一） 任务与输出目标

对每个位置统计左侧有多少个数严格小于当前值。

## （二） 建模与推导

固定当前鱼 i，它看到的鱼恰好是下标 0 到 i-1。枚举这些位置 j，把 `a[j]<a[i]` 翻译成计数器加一。相等不计入，位置在右侧也不计入。外层换鱼时重新把计数器置零。

## （三） 手算与过程

数组 `3 1 3 4` 的结果为 `0 0 1 3`；第三条鱼只计入 1，不计入左侧的 3。

## （四） 带注释实现

[完整源文件](../../code/P1428.cpp)

```cpp
#include <iostream>
using namespace std;



int main() {
    int n, a[100];
    cin >> n;
    for (int i = 0; i < n; ++i) cin >> a[i];
    for (int i = 0; i < n; ++i) {
        int count = 0; // 只统计当前鱼左侧的鱼。
        for (int j = 0; j < i; ++j)
            if (a[j] < a[i]) ++count;
        cout << count << (i + 1 == n ? '\n' : ' ');
    }
}
```

## （五） 复杂度

比较次数为 $0+1+\cdots+(n-1)$，时间 $O(n^2)$，保存输入占 $O(n)$。
