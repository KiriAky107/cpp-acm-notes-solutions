# P5717 三角形分类

[原题入口](https://www.luogu.com.cn/problem/P5717)

对应章节：三、解题方法论：从题意到代码 → （八） 用不变量和反例检查推导；三、解题方法论：从题意到代码 → （十） 从样例猜想到证明与构造。

## （一） 任务与输出目标

判断三边能否组成三角形，并按规定顺序输出角度与边长类别。

## （二） 建模与推导

先把三条边整理成 $a\le b\le c$。是否成三角形只需检查 $a+b>c$。成立后，用 $a^2+b^2$ 与 $c^2$ 的比较判定锐角、直角或钝角。等腰和等边是另外两项性质，不与角度分类互斥；等边三角形也同时输出等腰。

## （三） 手算与过程

3、4、5 输出直角；2、2、2 按顺序输出锐角、等腰、等边。

## （四） 带注释实现

[完整源文件](../../code/P5717.cpp)

```cpp
#include <bits/stdc++.h> // 竞赛模板中的常用标准库工具。
#define int long long   // 统一使用较大的整数类型。
#define endl '\n'       // 普通输出换行，避免逐行刷新。
using namespace std;

void solve() {
    long long a, b, c;
    cin >> a >> b >> c;
    if (a > b) swap(a, b);
    if (b > c) swap(b, c);
    if (a > b) swap(a, b); // 三次比较交换把短边放在前面。
    if (a + b <= c) { cout << "Not triangle\n"; return; }
    long long s = a * a + b * b;
    if (s == c * c) cout << "Right triangle\n";
    else if (s > c * c) cout << "Acute triangle\n";
    else cout << "Obtuse triangle\n";
    if (a == b || b == c) cout << "Isosceles triangle\n"; // 边长分类继续独立判断。
    if (a == c) cout << "Equilateral triangle\n";
}

signed main() {
    ios::sync_with_stdio(false); // 关闭同步，使用 cin 与 cout 完成输入输出。
    cin.tie(0), cout.tie(0);

    int T = 1; // 本题读入一组数据。
    // cin >> T; // 题目给出测试组数时开启，并在 solve 中处理一组。
    while (T--)
        solve();
}
```

头文件 `<bits/stdc++.h>` 汇总 GNU C++ 的常用标准库，包含本程序使用的流、容器与算法；这是序言竞赛模板中的包含方式。

## （五） 复杂度

固定次数的比较，时间 $O(1)$，额外空间 $O(1)$。
