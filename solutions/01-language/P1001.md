# P1001 A+B Problem

[原题入口](https://www.luogu.com.cn/problem/P1001)

对应章节：一、C++ 语法基础 → （一） 程序结构与编译。

## （一） 任务与输出目标

读入两个整数，输出它们的和。

## （二） 建模与推导

把输入中的两个数保存为 a、b，输出目标直接翻译成表达式 `a+b`。程序的动作依次是读入、计算、输出；题目不要求向用户显示输入提示，所以输出中只有答案。

## （三） 手算与过程

输入 `3 5`：a=3、b=5，相加得到 8。

## （四） 带注释实现

[完整源文件](../../code/P1001.cpp)

```cpp
#include <bits/stdc++.h>
#define int long long
#define endl '\n'
using namespace std;

void solve() {
    int a, b;
    cin >> a >> b;         // 一次读取题目给出的两个整数。
    cout << a + b << '\n'; // 加法表达式的结果就是输出目标。
}

signed main() {
    ios::sync_with_stdio(false); // 关闭同步，使用 cin 与 cout 完成输入输出。
    cin.tie(0), cout.tie(0);

    int T = 1; // 本题读入一组数据。
    // cin >> T; // 题目给出测试组数时开启，并在 solve 中处理一组。
    while (T--)
        solve();
}
```

## （五） 复杂度

时间 $O(1)$，额外空间 $O(1)$。
