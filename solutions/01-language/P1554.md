# P1554 梦中的统计

[原题入口](https://www.luogu.com.cn/problem/P1554)

对应章节：序言 → 建议的自学顺序与练习；五、数据结构与算法 → （二） 枚举与模拟。

## （一） 任务与输出目标

统计 M 到 N 每个整数的十进制表示中，0 到 9 出现的次数。

## （二） 建模与推导

外层枚举整数，内层用 `%10` 取出个位并用 `/10` 删除个位。每取出一个数码，就给对应计数器加一。把枚举变量和拆数变量分开，拆数过程不会改变外层的当前位置。

## （三） 手算与过程

10、11、12 中，0 出现 1 次，1 出现 4 次，2 出现 1 次。

## （四） 带注释实现

[完整源文件](../../code/P1554.cpp)

```cpp
#include <bits/stdc++.h>
#define int long long
#define endl '\n'
using namespace std;

void solve() {
    int m, n, count[10] = {};
    cin >> m >> n;
    for (int value = m; value <= n; ++value) {
        int x = value; // 在副本上逐位拆数。
        do {
            ++count[x % 10];
            x /= 10;
        } while (x > 0);
    }
    for (int digit = 0; digit < 10; ++digit)
        cout << count[digit] << (digit == 9 ? '\n' : ' ');
}

signed main() {
    ios::sync_with_stdio(false); // 关闭同步，使用 cin 与 cout 完成输入输出。
    cin.tie(0), cout.tie(0);

    int T = 1; // 本题读入一组数据。
    // cin >> T; // 题目给出测试组数时开启，并在 solve 中处理一组。
    while (T--)
        solve();
}
```

## （五） 复杂度

设区间长度为 K、最大数的十进制位数为 D，时间 $O(KD)$，十个计数器占 $O(1)$。
