# P1427 小鱼的数字游戏

[原题入口](https://www.luogu.com.cn/problem/P1427)

对应章节：一、C++ 语法基础 → （十五） STL：容器、迭代器与算法。

## （一） 任务与输出目标

依次读数，遇到 0 停止，把此前输入的数倒序输出。

## （二） 建模与推导

0 是输入结束标记，不属于需要输出的数据。把每个非零值追加到 vector，读完以后从最后一个位置向前遍历。读取阶段保存顺序，输出阶段改变遍历方向。

## （三） 手算与过程

输入 `3 8 5 0` 保存 3、8、5，输出 5、8、3。

## （四） 带注释实现

[完整源文件](../../code/P1427.cpp)

```cpp
#include <iostream>
#include <vector>
using namespace std;



int main() {
    vector<int> a;
    int x;
    while (cin >> x && x != 0) a.push_back(x); // 结束标记不存入容器。
    for (auto it = a.rbegin(); it != a.rend(); ++it)
        cout << *it << ' '; // 反向迭代器从最后一个元素开始访问。
    cout << '\n';
}
```

## （五） 复杂度

读到 K 个数据时，时间 $O(K)$，空间 $O(K)$。
